# Street Legacy driver portraits

Two original AI-generated atlas assets, created with the built-in image generation tool:
- `assets/drivers/men.png`: ten adult men, 5 columns × 2 rows.
- `assets/drivers/women.png`: ten adult women, 5 columns × 2 rows.

Godot AtlasTexture regions select portraits without splitting or recompressing the artwork. The source images remain in the project. Portrait choice has no gameplay effect.

Prompt set (one call for each gender, replacing [gender] with men or women):

Create ONE production game portrait atlas image for REVVED Street Legacy, exactly 5 columns and 2 rows, ten equal square cells, overall aspect ratio 5:2. Each cell contains ONE distinct fictional adult [man/woman] street-racing driver, head and shoulders, face centered with generous headroom, cropped upper chest. Exactly TEN [gender], ages 22–45, visibly diverse skin tones and ethnic appearances, distinct haircuts and faces, tasteful casual jackets/workwear/hoodies, no helmets, no weapons, no real people or celebrities. Premium stylized painted realism for an arcade racing game, detailed expressive faces, confident grounded personalities, cohesive warm gold rim light and cool slate shadows. Plain dark navy background fills every cell. Ten separate portraits on a rigid uniform invisible 5x2 grid; nothing crosses cell boundaries. No letters, words, numbers, logos, watermarks or decorative borders. Front or very slight three-quarter angle, eyes open, clearly distinguishable faces even at thumbnail size. Top row and bottom row each exactly five portraits. This is a single sprite-sheet asset, not a mockup. Desired canvas 2560 by 1024.

The returned images are used at native resolution; the requested resolution was a generation target, not a forced resize.
